# Efeitos sonoros

Todos os arquivos desta pasta são gerados por `scripts/gerar-sfx.sh`, por síntese no FFmpeg, sem amostras de terceiros. Podem ser usados livremente (domínio público / CC0).

| Arquivo | Quando usar |
|---|---|
| `whoosh.wav` | corte ou transição |
| `pop.wav` | entrada de cartão, preço, texto |
| `clique.wav` | item de lista, contagem |
| `impacto.wav` | revelação, batida forte |
| `sino.wav` | cupom, cartão final |
| `flash.wav` | foto, flash |

Regra: **um efeito por momento**, com pelo menos ~1,5 s entre eles, no quadro exato da palavra ou do corte. Efeito demais cansa.
